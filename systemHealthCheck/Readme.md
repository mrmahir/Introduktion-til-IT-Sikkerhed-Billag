A simple check on a few system administrative information such as FireWall or which ports you have open.
Could be quite cool to use after you might have played with port forwarding and you just want to make sure some important ports are closed.
Of course it can be further developed into a more comprehensive program, but I understood the purpose of this to be;
Show that I can make Bash, PowerShell and Python scripts, so I made all in one that works on both Linux and Windows, where a Python Script checks which OS you run and then runs either Linux audit or Windows Audit.
